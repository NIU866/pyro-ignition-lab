# 热解与着火模拟

用 Python 编写的桌面工具，用于比较不同气氛下的热解行为、拟合热重实验数据，并计算平板内的温度、固体残余和挥发物分布。这个项目会一直更新。

## 运行

需要 Python 3.10 或更高版本。桌面界面使用 Tkinter，无需安装第三方 Python 包。

```bash
python pyro_ignition_lab.py
```

Linux 或 macOS 上如果命令名是 `python3`，用 `python3` 运行。若系统把 Tkinter 单独打包，桌面模式需安装对应的系统包。

命令行可以直接运行空气和氮气示例并导出曲线。

```bash
python pyro_ignition_lab.py --csv example.csv
```

## 功能

| 入口 | 能做什么 |
| --- | --- |
| 主窗口 | 比较空气与氮气下的升温热解，查看失重、气相放热和模型着火判据 |
| TG 参数拟合 | 导入热重数据，用 GA 或 SCE-UA 拟合活化能、指前因子与残炭产率 |
| 一维平板热解 | 设置两面热边界，计算惰性气氛下的厚向导热、自定义多组分反应及残余质量 |
| 多指标反演 | 合并多个实验工况，利用质量、失重率和温度拟合参数，并在留出的实验工况上验证 |
| 二维截面 | 设置局部加热、孔内挥发物扩散、排气边界和厚度演化，回放并导出二维场 |

二维入口在「一维平板热解」窗口内。先设置材料、热边界和反应，再进入「二维截面」。查看温度、剩余固体和孔内挥发物浓度时，可用时间滑块切换时刻。可导出当前截面与时间历程 CSV，也可在一维平板窗口保存算例参数。

内置工况使用合成参数。二维传质采用单一等效挥发物扩散，厚度按原材料平均转化率整体变化。用于真实材料前，需要用独立实验校准和验证。

## 将实验曲线与预测对照

1. 在「一维平板热解」中设置实验样品厚度和传热边界，进入「多指标反演 → 实验工况」，点击「导出实验 CSV 模板」。
2. 填写至少两个严格递增的 `time_s` 时刻，并在每个有效时刻填写至少一项测量。可填写剩余质量 `remaining_mass_pct`（初始质量百分比）、失重率 `mass_loss_g_m2_s`（g/(m²·s)）、受热面温度 `front_C` 或背面温度 `back_C`（°C）。缺测留空。导入时会记录平板的工况设置。
3. 选中工况，点击「用当前材料对比」即可运行一次预测。程序读取平板当前的密度、导热系数、比热和反应设置，使用所选工况记录的厚度、边界和网格。单组实验即可使用这个入口。
4. 对于已完成的 GA 或 SCE-UA 反演，在「结果与验证」选择算法和工况，点击「查看工况曲线与残差」。可直接查看合成示例的结果，也可在此处检查独立留出的实验。

图中圆点为实测值，曲线连接实验时刻的模型预测。残差按「预测 − 实测」计算，正值表示模型高估。各指标分别显示有效观测数、RMSE、平均绝对误差和平均偏差，沿用该指标的单位。导出当前指标 CSV 可获得每个时刻的实测值、预测值与残差。缺测时保留预测，实测和残差列留空。

## 按组分输入反应模型

在「一维平板热解」点击「组分与反应表」。要先看一个填好的模型，点击「打开算例」，选用 [thermal_materials.json](examples/thermal_materials.json)。算例有两种初始组分、一种初始质量为零的残余物，以及两条反应。全部材料参数均为教学用合成值。

1. 在「组分与初始质量分数」每行填一个凝聚相名称和质量分数。各行合计为 1。只作为产物出现的组分填 0。
2. 在「From → To 反应」逐行填反应物、产物、原始指前因子 Z（1/s）、活化能 E（kJ/mol）和凝聚相产率（%）。可输入 `5.00E+05` 等科学计数。纯气体产物统一写 `gases`，凝聚相产率填 0。每行选一种反应热输入方式，单位见下表。
3. 在「组分热物性」点击「按组分补齐」，再将各行的公共初值改成该组分实测的密度、比热、导热系数和发射率。只有常物性数据时填前五列即可。热物性随温度变化时，再填写右侧的可选参数，使用水平滚动条可查看所有列。
4. 点击「应用到平板 → 运行一维模拟」。在「整体组分」切换各凝聚相与累计产气，或导出曲线与剖面 CSV。「二维截面」沿用同一张表。保存算例会保留全部输入和与之对应的一维结果。
5. 从 Excel 粘贴时直接选数据行，用制表符分列。组分表支持 2 列。反应表支持原来的 6 列或全部 8 列，分项反应热在后两列。物性表支持前 5 列或全部 12 列。公共热物性算例可参考 [component_network.json](examples/component_network.json)。

| 反应热输入方式 | 有效热 (kJ/kg) | ΔHsol (J/kg) | ΔHvol (J/kg) |
| --- | --- | --- | --- |
| 已知每千克反应物消耗的净吸热量 | 填净吸热量 | 留空 | 留空 |
| 已知凝聚相产物、挥发物各自的反应热 | 留空 | 填每千克生成的凝聚相产物对应的热量 | 填每千克从凝聚相挥发的气体对应的热量 |

两种输入均以吸热为正、放热为负。产率为 30% 时，每消耗 1 kg 反应物生成 0.30 kg 凝聚相产物和 0.70 kg 气体。例如 ΔHsol = −20,000 J/kg、ΔHvol = 100,000 J/kg，程序算得净吸热量为 64,000 J/kg，即有效热 64 kJ/kg。纯气体反应可将 ΔHsol 填 0。本模型直接指定凝聚相质量产率，Gpyro 的 χ 采用另一种定义。

每条反应采用一阶 Arrhenius 速率。同一 From 的竞争路径按速率分配消耗量，生成的中间组分从下一个反应半步起可继续反应。多指标反演的 GA 和 SCE-UA 可拟合各组分的参考密度、比热或导热、各反应的 E 或 log₁₀Z，以及参与产物生成的分项热。固定产率下，温度数据只能确定两项反应热的加权和，分别估计时需固定其中一项或提供独立热化学信息。

## 组分热物性与公式对照

以下公式编号来自 Chris Lautenberger 的 *Gpyro Technical Reference* v0.800（2014），对应用户指南中的 `sprops` 和 `rxns` 输入。[Gpyro 作者仓库中的技术参考](https://github.com/lautenberger/gpyro/blob/master/documentation/gpyro_technical_reference.pdf)

| 技术参考 | 软件输入和计算 |
| --- | --- |
| 式 (1)–(4)，组分体积与密度 | ρ(T) = ρ₀(T/Tr)ⁿρ。初始混合堆密度由质量分数和初始温度下各组分的堆密度计算。凝聚相内部以质量除以各自堆密度得到相对体积。 |
| 式 (7)–(8)，导热 | k(T) = k₀(T/Tr)ⁿᵏ + γσT³，按凝聚相体积分数加权。γ 的单位为 m，填 0 可关闭孔隙辐射导热项。σ 为斯忒藩–玻尔兹曼常数。 |
| 式 (9)–(12)，比热与焓 | 基线比热 c₀(T/Tr)ⁿᶜ，按质量加权。ΔHm 控制高斯熔化峰的面积，Tm 为峰中心，σm² 为方差。求解器对比热积分得到焓增量，包含指数为 −1 的对数极限。 |
| 式 (13)，表面发射率 | 两侧分别用邻近网格凝聚相的体积分数混合发射率。平板左栏给定的是已吸收的外部热通量。 |
| 式 (43)、(45)，恒定分项反应热 | 按该步生成的凝聚相与挥发物质量分别乘以 ΔHsol 和 ΔHvol，求和后进入温度方程。 |

T、Tr 和 Tm 使用 K。面板上的环境温度和曲线依旧使用 °C。新物性表默认为 Tr = 298.15 K，指数和熔化潜热默认为 0。启用物性表时每个凝聚相都需要一行，平板公共热物性输入框随之变灰。旧算例仍可使用公共常物性。

一维网格采用指定厚度，二维厚度按原料转化率整体变化。组分堆密度已经包含内部孔隙。对于凝聚相体积以外的剩余网格空间，软件使用固定的气体导热系数 0.026 W/(m·K) 和体积热容 1200 J/(m³·K)。组分热物性在每个导热步更新，反应温度增量按反应半步的中点组分计算。气相沿用等效挥发物传质模型。

## 数值验证与后续范围

在项目目录运行 `python -m unittest discover -s tests -v` 可复现以下检查。

- 恒定净热流加热均匀平板，与半无限体解析温度场对照。在 8 s、80 个网格、0.05 s 步长下，表面和网格中心的最大温差约 0.0194 °C。
- 含熔化峰的平板在给定净热流下，逐时比较总焓增量与边界输入热量；另有纯导热常物性极限、分项热符号及单位、整板质量守恒检查。
- 二维全宽均匀加热且厚度恒定时，与相同网格的一维模型逐深度对照。另行检查局部加热、伸缩和孔内气体库存，并用留出的合成工况验证两种优化器的回填参数。

示例工况计算到 45 s，受热面约 184.21 °C，背面约 53.30 °C，剩余固体占初始质量的 74.78%。这些结果用于复算和程序验证。材料预测准确度仍需与独立实验或对应的 Gpyro 算例对照。

后续顺序为反应级数与动力学函数、多气体组分与产率矩阵、分层初始条件与界面热阻，再到随时间变化的边界条件。这些功能目前尚未接入自定义平板模型。
