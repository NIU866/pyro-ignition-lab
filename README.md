# 热解与着火模拟

用 Python 编写的桌面工具，用于比较不同气氛下的热解行为、拟合热重实验数据，并计算平板内的温度、固体残余和挥发物分布。这个项目会一直更新。

## 运行

需要 Python 3.10 或更高版本。桌面界面使用 Tkinter，无需安装第三方 Python 包。

```bash
python pyro_ignition_lab.py
```

Linux 或 macOS 上如果命令名是 `python3`，用 `python3` 运行。若系统把 Tkinter 单独打包，桌面模式需安装对应的系统包。

命令行可以直接运行空气和氮气示例并导出曲线。

```bash
python pyro_ignition_lab.py --csv example.csv
```

## 功能

| 入口 | 能做什么 |
| --- | --- |
| 主窗口 | 比较空气与氮气下的升温热解，查看失重、气相放热和模型着火判据 |
| TG 参数拟合 | 导入热重数据，用 GA 或 SCE-UA 拟合活化能、指前因子与残炭产率 |
| 一维平板热解 | 设置两面热边界，计算分层试样的厚向导热、层间热流、多组分反应与逐气体质量收支 |
| 多指标反演 | 合并多个实验工况，利用质量、失重率和温度拟合参数，并在留出的实验工况上验证 |
| 二维截面 | 设置局部加热、排气边界和厚度演化，按气体查看和导出孔内浓度场 |

二维入口在「一维平板热解」窗口内。先设置材料、热边界和反应，再进入「二维截面」。查看温度、剩余固体和孔内挥发物浓度时，可用时间滑块切换时刻。可导出当前截面与时间历程 CSV，也可在一维平板窗口保存算例参数。

内置工况使用合成参数。二维传质可分别计算各气体的孔内扩散，厚度按原材料平均转化率整体变化。用于真实材料前，需要用独立实验校准和验证。

## 将实验曲线与预测对照

1. 在「一维平板热解」中设置实验样品厚度和传热边界，进入「多指标反演 → 实验工况」，点击「导出实验 CSV 模板」。
2. 填写至少两个严格递增的 `time_s` 时刻，并在每个有效时刻填写至少一项测量。可填写剩余质量 `remaining_mass_pct`（初始质量百分比）、失重率 `mass_loss_g_m2_s`（g/(m²·s)）、受热面温度 `front_C` 或背面温度 `back_C`（°C）。缺测留空。导入时会记录平板的工况设置。
3. 选中工况，点击「用当前材料对比」即可运行一次预测。程序读取平板当前的密度、导热系数、比热和反应设置，使用所选工况记录的厚度、边界和网格。单组实验即可使用这个入口。
4. 对于已完成的 GA 或 SCE-UA 反演，在「结果与验证」选择算法和工况，点击「查看工况曲线与残差」。可直接查看合成示例的结果，也可在此处检查独立留出的实验。

图中圆点为实测值，曲线连接实验时刻的模型预测。残差按「预测 − 实测」计算，正值表示模型高估。各指标分别显示有效观测数、RMSE、平均绝对误差和平均偏差，沿用该指标的单位。导出当前指标 CSV 可获得每个时刻的实测值、预测值与残差。缺测时保留预测，实测和残差列留空。

## 按组分输入反应模型

在「一维平板热解」点击「组分与反应表」。要先看一个填好的模型，点击「打开算例」，选用 [thermal_materials.json](examples/thermal_materials.json)。算例有两种初始组分、一种初始质量为零的残余物，以及两条反应。全部材料参数均为教学用合成值。

1. 在「组分与初始质量分数」每行填一个凝聚相名称。均匀试样在此填写质量分数，各行合计为 1，只作为产物出现的组分填 0。分层试样可将此列留空，在「材料分层」中填写每层配方。
2. 在「From → To 反应」逐行填反应物、产物、原始指前因子 Z（1/s）、活化能 E（kJ/mol）和凝聚相产率（%）。可输入 `5.00E+05` 等科学计数。纯气体产物统一写 `gases`，凝聚相产率填 0。每行选一种反应热输入方式，单位见下表。
3. 在「组分热物性」点击「按组分补齐」，再将各行的公共初值改成该组分实测的密度、比热、导热系数和发射率。只有常物性数据时填前五列即可。热物性随温度变化时，再填写右侧的可选参数，使用水平滚动条可查看所有列。
4. 点击「应用到平板 → 运行一维模拟」。在「整体组分」切换各凝聚相与凝聚相累计净挥发量，或导出曲线与剖面 CSV。「二维截面」沿用同一张表。保存算例会保留全部输入和与之对应的一维结果。
5. 从 Excel 粘贴时直接选数据行，用制表符分列。组分表支持 2 列。反应表支持原来的 6 列或 8 列，也可复制前 10 列（增加模型编号、n）或全部 12 列（再增加 Kcat、催化组分名称）。第 7、8 列为分项反应热。物性表支持前 5 列或全部 12 列。公共热物性算例可参考 [component_network.json](examples/component_network.json)。

| 反应热输入方式 | 有效热 (kJ/kg) | ΔHsol (J/kg) | ΔHvol (J/kg) |
| --- | --- | --- | --- |
| 已知每千克反应物消耗的净吸热量 | 填净吸热量 | 留空 | 留空 |
| 已知凝聚相产物、挥发物各自的反应热 | 留空 | 填每千克生成的凝聚相产物对应的热量 | 填每千克从凝聚相挥发的气体对应的热量 |

两种输入均以吸热为正、放热为负。产率为 30% 时，每消耗 1 kg 反应物生成 0.30 kg 凝聚相产物和 0.70 kg 气体。例如 ΔHsol = −20,000 J/kg、ΔHvol = 100,000 J/kg，程序算得净吸热量为 64,000 J/kg，即有效热 64 kJ/kg。纯气体反应可将 ΔHsol 填 0。凝聚相产率直接填写质量百分比。

旧算例默认采用一阶模型。生成的中间组分从下一个反应半步起可继续反应。多指标反演的 GA 和 SCE-UA 可拟合各组分的参考密度、比热或导热、各反应的 E 或 log₁₀Z，以及参与产物生成的分项热。固定产率下，温度数据只能确定两项反应热的加权和，分别估计时需固定其中一项或提供独立热化学信息。

## 做一个表层与基材的双层试样

在「一维平板热解 → 打开算例」选择 [layer_contact.json](examples/layer_contact.json)，点击「运行一维模拟」。在「层间热流」查看界面温度和传热方向，切换到「温度剖面」可看到同一深度处的两个单侧温度。该算例使用合成热物性，反应表留空，只计算导热。

要换成自己的试样，进入「组分与反应表」。先在「组分与初始质量分数」列出所有凝聚相，在「组分热物性」填写各自的密度、比热、导热系数和发射率。然后打开「材料分层」，从受热面向背面逐行填。下面两行与示例一致。

| 层名 | 厚度 (mm) | 初温 (°C) | 与下一层的接触热阻 (m²·K/W) | 涂层材料质量分数 | 基材材料质量分数 |
| --- | ---: | --- | ---: | ---: | ---: |
| 表层 | 0.7 | 留空 | 0.002 | 1 | 0 |
| 基材 | 2.3 | 留空 | 0 | 0 | 1 |

- 每层的组分质量分数合计为 1。初温留空时使用环境温度，也可逐层指定不同初温。热阻为 0 表示理想热接触，最后一层的后界面热阻填 0。可从 Excel 复制全部数据列并点击「粘贴分层表」，使用「上移」「下移」调整受热顺序。
- 点击「应用到平板」。首次填写或修改层厚时，平板总厚度更新为各层之和。之后单独修改试样总厚度，或在反演中使用另一厚度的工况时，各层按原厚度比缩放。厚向网格数至少等于层数，程序将单元边界对齐到层间界面。
- 「层间热流」中的正值表示热量由受热面向背面传递，界面温差满足 ΔT = q × R。温度测点正好落在界面时，读数取靠受热面一侧。「导出当前剖面 CSV」会在界面深度写出两行，分别是受热侧和背侧。时间历程 CSV 同时提供两侧温度与热流密度。
- 在「二维截面」可查看沿宽度连续的材料层。虚线标出层界面，悬停和截面 CSV 提供层名与单元实际深度。启用厚度演化后，各层随试样按同一比例伸缩。接触热阻只作用于界面传热，气体继续按孔隙扩散模型传质。
- 在「多指标反演」中可勾选某个界面的接触热阻，用 GA 或 SCE-UA 对照实测受热面、背面温度拟合，并在留出工况上验证。

该算例设定 2,000 W/m² 恒定受热通量，背面与 25 °C 环境以 80 W/(m²·K) 对流换热，关闭辐射和正面对流。串联热阻给出的稳态背面温度为 50.00 °C，界面受热侧为 65.50 °C、背侧为 61.50 °C，受热面为 75.50 °C。运行至 600 s 时，程序所得温度按两位小数舍入与这些值相同。

## 逐气体填写产率与查看排气

在「一维平板热解 → 打开算例」中选择 [gas_yields.json](examples/gas_yields.json)，然后点击「运行一维模拟」。结果图的「气体质量收支」下拉框可切换气体 A 和气体 B。要修改配比，打开「组分与反应表」。

| 反应 | 凝聚相产率 | 气体 A | 气体 B |
| --- | ---: | ---: | ---: |
| matrix → residue | 30% | 0.8 | 0.2 |
| binder → gases | 0% | 0.3 | 0.7 |

例如，第一条反应消耗 1 kg 的 matrix 时，留下 0.30 kg 的 residue。余下 0.70 kg 分给气体 A 和 B，分别生成 0.56 kg 和 0.14 kg。

1. 在「气体组分」为每种气体填一行。自由扩散系数 D 的单位为 m²/s，填 0 可关闭该气体的扩散。D 留空时，一维采用 2×10⁻⁶ m²/s，二维采用截面窗口设置的值。初始孔内浓度和开放面外界浓度均用 kg/m³ 孔隙，默认为 0。
2. 在「气体产率矩阵」逐格填写，也可从 Excel 复制整个数值区，点击「粘贴矩阵」。行顺序对应反应，列顺序对应气体。每格是 kg 气体 / kg 凝聚相净挥发量，空格计 0。有挥发量的行代数和须为 1，凝聚相产率为 100% 的行全填 0。
3. 正系数表示生成，负系数表示消耗。例如一行填 `−0.2`、`1.2`，表示每净挥发 1 kg 固体，同时消耗 0.2 kg 第一种气体并生成 1.2 kg 第二种气体。在输入框中使用半角减号 `-0.2`。需要的气体可来自初始孔内库存、其他反应或开放面流入。程序按当地可用量限制反应进度，并同步更新固体消耗和反应热。
4. 点击「应用到平板 → 运行一维模拟」。选择「气体质量收支」查看累计生成、累计消耗、孔内存量及正背面净排出，单位均为初始干样质量的百分比。对于每种气体，初始存量 + 累计生成 − 累计消耗 = 当前存量 + 两面累计净排出。净排出为负表示从外界流入。
5. 要看气体聚集在哪里，进入「二维截面 → 运行二维模拟」，在图上方选择一种气体，移动时间滑块并悬停在网格上。当前截面 CSV 保存各单元浓度，时间历程 CSV 保存各气体收支。保存算例可恢复一维结果与所选气体，二维截面按保存的设置重新计算。

一维的固定孔隙率和开放面在「气体组分」设置。二维在截面窗口单独设置起止孔隙率、排气面及伸缩率。各气体独立做 Fick 扩散，有效扩散系数为 D × 孔隙率的 1.5 次方。当前平板传质计算忽略压力驱动流动、气体携热与气相均相反应。

按示例设置运行到 45 s，剩余固体为初始干样质量的 74.78%。气体 A 累计生成 15.38%，其中 14.88% 已从正面排出、0.50% 留在孔内。气体 B 累计生成 9.83%，其中 7.87% 已从正面排出、1.96% 留在孔内。两种气体名称和产率均用于演示。

## 为每条反应选择动力学模型

进入「一维平板热解 → 组分与反应表 → From → To 反应」，点击「定位动力学列」。在每一行的下拉框选模型，再填写适用的级数 n。点击「模型公式」可随时查阅下表。在「多指标反演」中，GA 和 SCE-UA 可以拟合所选模型的 n；模型 9 指定催化组分后也可拟合 Kcat。

温度项为 $k(T)=Z\exp[-E/(RT)]$。表中 $a$ 是这一个网格单元内该反应物的转化率，$u=1-a$。速率按 $k(T) f(a)$ 计算，归一化基准是这份反应物的初始质量加上截至当前已生成的质量。这样，初始分数为零的中间产物也可以继续参与后续反应。

| 编号 | 动力学模型 | 转化率函数 $f(a)$ |
| --- | --- | --- |
| 0 | n 阶反应 | $u^n$ |
| 1 | 成核与生长 | $u[-\ln u]^{1-n}/n$ |
| 2 | 相界反应 | $u^n$ |
| 3 | 平面扩散 | $1/(2a)$ |
| 4 | 圆柱扩散 | $1/[-\ln u]$ |
| 5 | 球形扩散 | $3/[2(u^{-1/3}-1)]$ |
| 6 | 扩散经验式 | $3/(2a u^{1/3})$ |
| 7 | 幂律 | $a^{1-n}/n$ |
| 8 | 积分级数式 | $u^{1-n}/n$ |
| 9 | 催化反应 | $u^n(1+K_{cat} a_{cat})$ |

模型 0、2、9 支持非负 n，模型 1、7、8 要求 n 大于 0。模型 0 与 2 对相同的 n 会给出相同结果。扩散模型 3–6 的 n 留空或填默认值 1。模型 9 的催化组分按名称引用组分表，允许引用反应物自身，Kcat 为非负数。催化因子取反应半步开始时该组分的转化率。相同速率函数的竞争路径按速率分配质量，不同函数的竞争路径使用自适应子步积分。成核、幂律和扩散模型从零转化率的积分解起步。

**等温对照算例**把两种组分各设为初始试样质量的 50%，保持 25 °C，令两者的速率常数同为 0.1 s⁻¹，仅改变 n。10 s 时的结果可用解析解直接核对。运行后在「整体组分」里切换曲线。[打开算例文件](examples/reaction_orders.json)

| 组分 | n | 占该组分初始质量 | 占整个试样初始质量 |
| --- | --- | --- | --- |
| 一级组分 | 1 | 36.79% | 18.39% |
| 二级组分 | 2 | 50.00% | 25.00% |

## 组分热物性与公式对照

下表沿用 C. Lautenberger（2014）技术参考第 2 节和第 3.5 节的式号，便于核对各输入量的物理定义。相关推导也可参见[作者的学位论文](https://escholarship.org/uc/item/7wz5m7dg)。

| 技术参考 | 软件输入和计算 |
| --- | --- |
| 式 (1)–(4)，组分体积与密度 | ρ(T) = ρ₀(T/Tr)ⁿρ。初始混合堆密度由质量分数和初始温度下各组分的堆密度计算。凝聚相内部以质量除以各自堆密度得到相对体积。 |
| 式 (7)–(8)，导热 | k(T) = k₀(T/Tr)ⁿᵏ + γσT³，按凝聚相体积分数加权。γ 的单位为 m，填 0 可关闭孔隙辐射导热项。σ 为斯忒藩–玻尔兹曼常数。 |
| 式 (9)–(12)，比热与焓 | 基线比热 c₀(T/Tr)ⁿᶜ，按质量加权。ΔHm 控制高斯熔化峰的面积，Tm 为峰中心，σm² 为方差。求解器对比热积分得到焓增量，包含指数为 −1 的对数极限。 |
| 式 (13)，表面发射率 | 两侧分别用邻近网格凝聚相的体积分数混合发射率。平板左栏给定的是已吸收的外部热通量。 |
| 式 (43)、(45)，恒定分项反应热 | 按该步生成的凝聚相与挥发物质量分别乘以 ΔHsol 和 ΔHvol，求和后进入温度方程。 |

T、Tr 和 Tm 使用 K。面板上的环境温度和曲线依旧使用 °C。新物性表默认为 Tr = 298.15 K，指数和熔化潜热默认为 0。启用物性表时每个凝聚相都需要一行，平板公共热物性输入框随之变灰。旧算例仍可使用公共常物性。

一维网格采用指定厚度，二维厚度按原料转化率整体变化。组分堆密度已经包含内部孔隙。对于凝聚相体积以外的剩余网格空间，软件使用固定的气体导热系数 0.026 W/(m·K) 和体积热容 1200 J/(m³·K)。组分热物性在每个导热步更新，反应温度增量按反应半步的中点组分计算。填写气体组分表后，程序分别求解每种气体的孔内扩散。气体表留空时，二维仍使用等效挥发物。

## 数值验证与后续范围

在项目目录运行 `python -m unittest discover -s tests -v` 可复现以下检查。

- 逐项核对 10 种动力学模型的等温积分解，测试竞争反应的各路径质量、中间产物的生成与再次消耗、催化因子的时间步收敛，以及 GA / SCE-UA 对合成反应级数的回收。
- 对双面排气的均匀平板，用扩散方程的解析级数核对两种气体随时间减少的孔内存量。另行检查封闭库存、外界流入、竞争消耗、逐组分收支及一维与二维的对应关系。
- 以双层串联热阻核对稳态受热面、背面、界面温度及穿层热流。另行检查绝热双层的能量守恒、局部质量与整板质量的加权、非均匀网格上的气体扩散和独立工况的接触热阻反演。
- 恒定净热流加热均匀平板，与半无限体解析温度场对照。在 8 s、80 个网格、0.05 s 步长下，表面和网格中心的最大温差约 0.0194 °C。
- 含熔化峰的平板在给定净热流下，逐时比较总焓增量与边界输入热量；另有纯导热常物性极限、分项热符号及单位、整板质量守恒检查。
- 二维全宽均匀加热且厚度恒定时，与相同网格的一维模型逐深度对照。另行检查局部加热、伸缩和孔内气体库存，并用留出的合成工况验证两种优化器的回填参数。

示例工况计算到 45 s，受热面约 184.21 °C，背面约 53.30 °C，剩余固体占初始质量的 74.78%。这些结果用于复算和程序验证。材料预测准确度仍需与独立实验或已验证的基准算例对照。
